# Codex Float M1 Core MVP Implementation Plan

> **For Hermes:** Execute task-by-task with tests before implementation and verify the real Windows executable.

**Goal:** Build a working Windows 11 x64 Codex Float vertical slice that displays live Codex quota and local today/7-day/30-day Token totals in an original floating UI.

**Architecture:** A Tauri 2 shell hosts a React/TypeScript UI. Rust owns all local data access: an app-server JSON-RPC quota provider and an incremental JSONL Token collector backed by SQLite. The renderer receives allow-listed domain DTOs only.

**Tech Stack:** Tauri 2, React, TypeScript, Vite, Vitest, Rust, rusqlite, serde/serde_json, chrono.

**Test-first behaviors:**

- Format Token totals as K/M without model or price dimensions.
- Render dynamic quota-window labels from actual duration.
- Represent data state as live/stale/unavailable and Token coverage explicitly.

## Task 3: Implement incremental JSONL Token collection

**Files:**
- Create: `apps/desktop/src-tauri/src/token_usage.rs`
- Test: inline Rust fixture tests

**Test-first behaviors:**

1. Repeated cumulative snapshot is ignored.
2. Cumulative counter decrease is handled as a reset.
3. Scanning the same file twice is idempotent.
4. Appending one event increments only once.
5. Stored SQLite state contains hashes/cursors/aggregates but no prompt, response, email or raw session path.

**Verification:**

```bash
cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml token_usage
```

## Task 4: Implement the app-server quota provider

**Files:**
- Create: `apps/desktop/src-tauri/src/quota.rs`
- Test: parsing tests using synthetic allow-listed protocol responses

**Behavior:**

- Spawn `codex app-server --stdio`.
- Initialize JSON-RPC and call `account/rateLimits/read`.
- Normalize zero, one or multiple windows.
- Return structured unavailable state on discovery, timeout, protocol or auth failure.
- Never expose email, tokens or raw responses through IPC/logging.

## Task 5: Expose minimal Tauri commands

**Files:**
- Create: `apps/desktop/src-tauri/src/main.rs`

**Commands:**

- `get_dashboard_snapshot`
- `set_window_expanded`

The snapshot combines quota and Token results without silently combining local and account usage semantics.
